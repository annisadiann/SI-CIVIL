# SI-CIVIL: Sistem Kalkulasi Teknik Sipil
Platform komputasi berbasis web untuk mendukung akurasi perhitungan teknik sipil berdasarkan standar SNI.

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repository ini:
   ```bash
   git clone [https://github.com/username/SI-CIVIL.git](https://github.com/username/SI-CIVIL.git)
   cd SI-CIVIL

Install dependencies:
pip install -r requirements.txt

Jalankan aplikasi Streamlit:
streamlit run main.py
